# 过去三个月可靠性回测

Last updated: 2026-05-28

本文回答一个具体问题：过去三个月的公开历史数据，是否支持当前交易系统的风险权限规则。

结论先行：本次回测支持继续保留“缺 A2 不允许 09:28 追强，必须降级到 09:35 承接确认”的规则；但它不能证明系统已经具备长期盈利能力，也不能证明真实竞价队列、撤单和封单因子有效。

## 1. 回测范围

| 项目 | 取值 |
| --- | ---: |
| 窗口 | 2026-02-28 至 2026-05-27 |
| 数据源 | 腾讯公开前复权日线 |
| 股票池 | `config/backtest_universe.example.csv` 主板样本 |
| 有效股票数 | 99 |
| Stock-days | 5,635 |
| 2% 高开追强候选 | 60 |
| 强收盘隔夜候选 | 332 |
| 09:35 显式确认样本 | 0 |

2026-05-28 仍未形成完整日线，因此本次回测截止到 2026-05-27。

## 2. 验证方法

本次不是选股收益回测，而是权限规则回测。

回测用一个不安全代理策略模拟“缺 A2 仍然在 09:28 追高”：

1. 当日开盘相对前收盘高开不低于 2%。
2. 前一日收盘价不低于 20 日均线。
3. 假设开盘追入。
4. 计划止损为 2.5%，目标为 5%，即目标赔率约 2R。
5. 若当日最低价触发 1R 止损，记为失败。
6. 若高开后收盘低于开盘，记为误放行代理。

当前系统规则与这个代理策略对比：

1. 缺 A2 时不允许 09:28 追强。
2. 候选只能降级为 09:30-09:35 承接确认。
3. 09:35 后仍必须同时满足板块共振、市场状态、VWAP/开盘价承接和止损距离。

本次优化后，回测额外增加五类指标：

1. `missed_valid_plan_proxy`：被缺 A2 规则拦截，但日线代理结果达到至少 0.5R 的候选比例，用来衡量机会错杀风险。
2. `market_regime_summary`：用样本股涨跌宽度、均值收益、强弱分布生成市场状态代理分层。
3. `role_summary`：用相对涨幅、成交量和收盘强弱生成龙头/中军代理、趋势中军代理、弱跟风代理。
4. `confirmation_sample_count`：显式 09:35 价格和 VWAP 样本数。
5. `confirmation_lift`：有 09:35 样本时，比较确认组与失败组的平均 R 差异。

## 3. 回测结果

| 指标 | 结果 | 含义 |
| --- | ---: | --- |
| 2% 高开追强候选 | 60 | 三个月内触发样本偏少，不足以放宽规则 |
| 不安全追强误放行率 | 55.0% | 超过一半高开追强候选收盘表现不支持追强 |
| 1R 止损触发率 | 33.3% | 三分之一候选盘中触发计划止损 |
| 高开回落率 | 51.7% | 单纯高开并不等于有效承接 |
| 收盘跌回前收以下 | 13.3% | 一部分开盘强势完全失败 |
| 平均结果 R | 0.015 | 平均值接近零，不能证明追强有优势 |
| 中位结果 R | -0.114 | 中位数为负，说明典型样本偏弱 |
| 平均 expected-R 偏差 | -0.185 | 若用乐观先验，实际结果低于预期 |
| 平均绝对 expected-R 偏差 | 0.884 | 校准误差较大，不能给精确胜率 |
| 强收盘后次日坏跳空率 | 3.6% | 尾盘计划仍需次日开盘验证 |
| 当前缺 A2 规则误放行率 | 0.0% | 规则层面直接拦截 09:28 追强权限 |
| 当前缺 A2 规则拦截候选 | 60 | 60 个风险候选被推迟到开盘承接确认 |
| 机会错杀代理 | 25.0% | 15/60 个被拦截候选后来达到至少 0.5R，说明不能只会拦截，还必须做 09:35 重新筛选 |
| 09:35 显式确认样本 | 0 | 当前公开三个月回测没有稳定 09:35 样本，不能证明确认层收益 |

### 3.1 市场状态代理分层

| 市场状态代理 | 样本 | 误放行率 | 1R止损率 | 平均R | 中位R |
| --- | ---: | ---: | ---: | ---: | ---: |
| 强进攻代理 | 5 | 60.0% | 20.0% | -0.078 | -0.098 |
| 轮动代理 | 10 | 60.0% | 20.0% | -0.206 | -0.486 |
| 退潮 | 28 | 53.6% | 42.9% | 0.081 | -0.205 |
| 冰点修复代理 | 9 | 33.3% | 22.2% | 0.427 | 0.297 |
| 混沌代理 | 8 | 75.0% | 37.5% | -0.342 | -0.564 |

市场状态分层的样本仍然偏小，不能直接作为胜率参数。但它已经说明两点：

1. 混沌和轮动环境下，高开追强质量很差，必须继续压低风险预算。
2. 冰点修复代理表现较好，但只有 9 个样本，不能据此放大；只能允许核心反包或低位首启的小仓试错。

### 3.2 角色代理分层

| 角色代理 | 样本 | 误放行率 | 1R止损率 | 平均R | 中位R |
| --- | ---: | ---: | ---: | ---: | ---: |
| 弱跟风代理 | 31 | 100.0% | 58.1% | -0.742 | -1.000 |
| 龙头/核心代理 | 22 | 9.1% | 9.1% | 0.725 | 0.443 |
| 趋势/中军代理 | 7 | 0.0% | 0.0% | 1.142 | 0.891 |

这是本次回测最有交易价值的发现：问题不只是“缺 A2 不追强”，而是必须把追强候选先做角色过滤。弱跟风高开几乎没有交易价值；龙头、核心、中军代理才值得进入 09:35 确认池。

## 4. 产品判断

本次回测的专业判断不是“系统已可靠盈利”，而是：

1. 三个月样本没有支持放宽 09:28 追强权限。
2. 缺 A2 时直接追强的误放行率、高开回落率和止损触发率都偏高。
3. 当前系统把这类机会降级为 09:35 承接确认，是合理的风险权限设计。
4. 三个月 60 个高开追强候选低于 300 个最低候选阈值，因此不能用本次结果调整 base rate 或放宽权限。
5. 弱跟风代理组必须默认禁止追强；龙头/核心/中军代理组可以进入 09:35 确认，但不能跳过 VWAP、板块共振和止损距离。
6. 25.0% 机会错杀代理说明系统不能只会拦截，还必须在 09:35 重新筛选被拦截候选。
7. 这验证的是 guardrail 稳定性和初步分层价值，不是交易收益稳定性。

换句话说，过去三个月的数据支持系统继续保守，但不是简单空仓保守；更专业的处理是：缺 A2 不在 09:28 追，09:35 只重新放行核心/中军/趋势确认票，弱跟风直接排除。

## 5. 不能证明的部分

本次仍不能证明以下能力：

1. 真实 A2 竞价成交额、09:20 后撤单、封单和队列因子的独立有效性。
2. 09:35 承接确认在所有历史日的完整收益表现，因为当前三个月回测没有稳定显式 09:35 price/VWAP 样本。
3. 用户真实执行后是否更少计划外交易、更少无止损交易。
4. 长期收益率、最大回撤、夏普比率或相对指数超额收益。

这些必须依赖后续的 prediction/outcome/behavior 日志和真实 A2 样本继续验证。

## 6. 下一步验收标准

后续只有满足以下条件，才考虑放宽权限或调整概率：

| 数据 | 最低样本 | 用途 |
| --- | ---: | --- |
| 真实 A2 样本 | 20-60 个交易日 | 比较 A2 确认组与无 A2 组的误放行率、09:35 证伪率 |
| 开盘候选样本 | 300+ 个 | 校准缺 A2、09:35 承接和追强候选的 base rate |
| prediction/outcome 匹配样本 | 100+ 个事件 | 计算 Brier score、expected-R 偏差和错误类型 |
| behavior 风险日志 | 4-8 周 | 验证无止损、计划外交易和 override 是否下降 |
| 角色标注样本 | 300+ 个候选 | 验证龙头/核心/中军/补涨/跟风的真实分层胜率 |
| 09:35 price/VWAP 样本 | 300+ 个候选 | 计算 confirmation lift 和 missed valid plan rate |

在这些样本完成前，当前结论应保持克制：系统的风险权限规则通过了三个月公开数据压力测试，但收益有效性仍处在待验证阶段。
